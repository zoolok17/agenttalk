Universal pill for metadata — status, message kind, severity, thread state. Mono, tint background, one `tone` prop.

```jsx
<Chip tone="ok">Working</Chip>
<Chip tone="accent">review-request</Chip>
<Chip tone="danger" solid>GATE HOLD</Chip>
```

Tones: `neutral, accent, ok, info, warn, attn, danger, violet, teal, gray`. `solid` fills the pill (white text) for source tags.
